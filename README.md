# DealerAdGen

DealerAdGen은 중고차 매물 정보와 사진으로 소셜·웹·이메일·인쇄 광고 이미지를 만들고, 세로 규격 소재를 WebM 영상으로 내보내는 한국어 광고 제작기입니다.

## 사용 방법

1. 차량 상세 페이지 링크는 참고용으로 붙여 넣고 **가져오기**를 누릅니다. 브라우저의 보안 제한 때문에 외부 매물 페이지 내용을 자동으로 읽지는 않으므로 제조사·모델·가격은 직접 확인해 입력합니다.
2. 차량 사진을 올리고 차량명, 색상, 가격, 헤드라인, 행동 유도 문구를 입력합니다.
3. 광고 유형, 디자인 분위기, 게시 규격과 출력 품질을 선택합니다.
4. **광고 만들기**를 누르면 선택한 규격별 이미지를 브라우저에서 합성합니다. 미리보기에서 PNG를 저장할 수 있고, 세로형 결과에서는 5초 길이 WebM을 만들고 재생할 수 있습니다.

이미지는 브라우저 안에서 처리됩니다. 원격 서버에 업로드하지 않습니다. 로고 오버레이를 켜고 매장 로고를 올리면 미리보기와 파일에 같이 들어갑니다.

## 구현 범위

- 반응형 한국어 편집 화면: 유형, 모양, 채널 규격, 매물 정보, 사진, 로고, 출력 품질
- PNG 광고 소재 제작과 미리보기, 삭제 및 다운로드
- 세로형 WebM 영상 내보내기 및 브라우저 미리보기
- 이미지 입력은 현재 광고 레이아웃 합성이며 외부 생성형 이미지 모델, VIN 디코더, 매물 링크 크롤러, 계정 저장/크레딧 결제는 연결하지 않았습니다. 해당 연결에는 별도 API 서버와 인증 정보가 필요합니다.

## 로컬 실행

```sh
npm ci
npm run dev
```

프로덕션 빌드와 Pages 파일 생성:

```sh
npm run build
npm run pages:copy
```
